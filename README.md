GaBeast Mobile — setup

To play: open the hosted index.html URL in your phone browser. Tap the direction pad to walk or select, Select to confirm, and Back to return. The normal game option buttons also work by touch.

To host on GitHub Pages: create a repository, upload index.html to its root, then enable Pages in Settings > Pages using Deploy from a branch, main, / (root). Open the resulting site URL on your phone. The game is a single self-contained page, so no separate sprite files are required.

Game progress is saved in this browser's local site storage. Use the same browser and site URL to continue; opening a different URL or a local file creates a separate save.
